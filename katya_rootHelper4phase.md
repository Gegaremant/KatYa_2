# Генеральный План: Отращиваем Кате "Руки" (KatYa 3.0)

Ваш запрос описывает полноценного **системного ИИ-Агента**, способного управлять всем устройством, автоматизировать рутину без API, контролировать другие приложения и работать с рут-правами. Так как это гигантский объем работы, требующий серьезных архитектурных изменений, я разбил его на логические "Эпики" (фазы). 

## User Review Required
> [!IMPORTANT]
> Это долгосрочный план развития, который превратит Катю в супер-ассистента. 
> Пожалуйста, посмотрите на приоритеты фаз ниже. **С какой фазы начнем прямо сейчас?** (Я настоятельно рекомендую начать с **Фазы 1**, так как без фундамента в виде Root и чтения экрана мы не сможем реализовать остальное).

## Фаза 1: Фундамент (Root, Ассистент по умолчанию, Зрение)
*Здесь мы даем Кате базовые права и инструменты для управления телефоном.*
1. **Ассистент по умолчанию:** Реализация `VoiceInteractionService` и `android.app.role.NOTES`, чтобы Катя вызывалась удержанием кнопки Home / жестом, и стала системным помощником.
2. **Root-доступ (AppManager, Мониторинг):** Создание `RootCommandExecutor`. Катя сможет выполнять `su -c`, использовать `am`, `pm`, `dumpsys` для отслеживания активности батареи и заморозки приложений.
3. **Чтение экрана и имитация нажатий (Парсинг упрямых):** Создание `KatyaAccessibilityService` для чтения элементов экрана (UI-дерева) и кликов без API. Альтернативно — снятие скриншотов через Root (`screencap`) и анализ локальной Vision-моделью + нажатия через `input tap`.

## Фаза 2: Базовые Интеграции и Заметки
*Даем Кате память и доступ к системным инструментам.*
1. **Экосистема Заметок:**
   - Локальные встроенные заметки (БД Кати).
   - Интеграция с локальными приложениями (через Android Intents).
   - Облачные заметки (Google Keep и др.) — так как у Keep нет открытого API для обычных юзеров, будем использовать наш AccessibilityService (из Фазы 1), чтобы "открывать Keep и записывать туда", либо неофициальные методы.
2. **Календарь:** Интеграция с системным Календарем Android (`CalendarContract`) для чтения/записи расписания.
3. **Яндекс Музыка:** Управление воспроизведением (MediaSession API или системные Intents).

## Фаза 3: Коммуникации и Умный дом
1. **Управление Email (IMAP/SMTP):** Добавление email-клиента внутрь Кати. Поддержка Яндекс, Mail.ru, Gmail (с App Passwords). Чтение писем голосом и отправка ответов под диктовку.
2. **Защита от спама:** Реализация `CallScreeningService` — Катя сможет блокировать звонки/СМС по базе или даже "брать трубку" (если позволит API) и общаться со спамерами.
3. **Умный дом (Алиса / Локальный сервер):** Интеграция с Yandex Smart Home API или локальным Home Assistant (Webhook/REST) для включения света, розеток и т.д.

## Фаза 4: Автономность и Управление Сетью
1. **Управление VPN:** Мониторинг состояния сети. Если интернет пропал, локальная LLM Кати (запущенная на самом телефоне) принимает решение переподключить VPN через Root-команды или Intents (OpenVPN/Wireguard).
2. **Магазин Root-приложений (awesome-android-root):** Обучение Кати искать, рекомендовать и автоматически скачивать/устанавливать полезные root-утилиты (через `su -c pm install`).
