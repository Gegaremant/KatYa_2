# План модернизации KatYa (v3.1.2 -> v.3.1.3)

## 1. Исправление багов и прокси
- **Deepseek Proxy:** Исправить баг с вводом текста (каретка сдвигается влево после каждого символа). Изучить ранние билды, где функция работала корректно.
- **Подключение прокси:** Прокси по-прежнему не подключается. Добавить подробное логирование для диагностики и исправить проблему с подключением.
- **Состояние подключения:** Состояние всегда пишет «нет соединения». Реализовать отображение скорости соединения, количества токенов или других данных, которые однозначно подтверждают активное соединение с моделью.

## 2. Настройки и UI
- **Цветовая схема (Dark Mode):** 
  - Режимы работы: сделать шрифт светлым на темном фоне.
  - Сделать светлыми надписи: «Распознание речи (слух)», «Синтез речи (голос)», «тональность», «скорость», «режим работы», «собеседник», «только по делу», «задержка отправки».
- **Интерфейс чата:** Полностью убрать верхнюю серую неинформативную плашку из основного интерфейса чата.
- **Интерфейс почты:** При добавлении почтового ящика использовать нормальные значки приложений и исправить их растягивание/отображение.
- **Claude API:** Сделать неактивными (серыми) пункты, которые находятся в разработке.

## 3. Голос и Слух
- **Настройки голоса (Синтез речи):**
  - Убрать выбор между мужским и женским голосом, оставить 1 вшитый голос.
  - Убрать надписи «предустановленные голоса», «голос 1», «голос 2».
  - Починить ползунки регулировки тональности и скорости (чтобы они меняли в том числе и системный голос).
  - Добавить озвучку после отпускания ползунка: «Это теперь будет мой голос?».
- **Настройки слуха (Распознавание речи):**
  - Перенести регулятор «Задержка отправки» в режим слуха (отвечает за время тишины, после которого собеседник считается завершившим фразу).

## 4. Режимы работы и Модели
- **Названия и поведение режимов работы:**
  - **«Только по делу»**: ответы краткие, без лишних деталей и уточнений.
  - **«Собеседник»**: рассказывает всё, что знает, уточняет, поддерживает разговор, сама инициирует новые темы.
  - **«Сыскун»**: поиск заданной информации и выдача в виде списка со ссылками на источники (без болтовни). Позже будет поддержано локальной моделью.
- **Локальные модели:** 
  - При выборе локальной модели давать прямую ссылку на отфильтрованную подборку подходящих моделей на Hugging Face (вместо корня HF).
  - Предусмотреть концепцию локальной модели, которая будет выполнять всё (голос, слух, зрение, поиск в интернете). Настойчиво предлагать пользователю скачать такую модель.

## 5. Системные функции
- **Godmode:** Выдавать абсолютно все существующие и возможные системные права при активации, чтобы не было никаких ограничений в возможностях.
