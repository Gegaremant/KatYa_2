## 3. Архитектура: Автоматический Демон и Логи
- [x] 3.1 **Логи Root:** Исправить ведение логов root-доступа (теперь пишется в `/data/media/0/Katya/` минуя FUSE).
- [x] 3.2 **Демон Задач:** Внедрен `DaemonService` и `TaskScheduler`, которые в фоне выполняют запланированные скрипты и напоминания.

## 4. Архитектура: Песочница (Termux)
- [x] 4.1 Сразу мигрировать с Alpine на **Termux** (используем `RootfsDownloader` для `bootstrap.zip`).
- [x] 4.2 Убедиться, что в Termux работают `python3`, `sqlite3`, `curl` и есть доступ к `/sdcard` (пакеты ставятся через `apt`, бинды проброшены в `ProotExecutor`).

## 5. Сеть: VLESS / Xray
- [x] 5.1 Вшить базовый бинарник `xray-core` прямо в приложение, чтобы он был доступен оффлайн (добавлен как `libxray.so` в `jniLibs`).
- [x] 5.2 Сохранить для Кати возможность программно скачивать и устанавливать инструменты, обходя ограничения Android-манифеста (с миграцией на Termux это решено штатно через `apt`).

## 6. Android Permissions (GOD_MODE)
- [x] 6.1 Добавить в `AndroidManifest.xml` **все возможные** системные разрешения, существующие в Android, для обеспечения максимального GOD_MODE.
- [x] 6.2 Запрашивать их автоматически через Root/pm grant.

## 7. Звук и Audio Focus
- [x] 7.1 Переработка кнопки микрофона: отказаться от диалога-перекрытия экрана (системное синее окно), вставлять распознанный текст напрямую в поле ввода. Отправка будет происходить автоматически при паузе (onEndOfSpeech).
- [x] 7.2 Переработка Audio Focus: приглушение (duck) заменяем на эксклюзивный фокус. Музыка (если играла) ставится на паузу во время прослушивания и ответа, а затем возвращается.

- [x] 8.2 Системные движки: Android SpeechRecognizer (по умолчанию для STT) и Android System TTS (по умолчанию для TTS).
