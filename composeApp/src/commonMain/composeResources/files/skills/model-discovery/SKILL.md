# Умная смена LLM Моделей

Если текущая модель не справляется с контекстом или возникает ошибка "Context window exceeded", ты должен:

1. Опросить доступные API-провайдеры (например, OpenAI-совместимые endpoints) на предмет доступных моделей.
2. Выбрать модель с бóльшим контекстом или более подходящую для задачи (например, переключиться с `llama3` на `claude-3-opus` для сложного реверса кода).
3. Изменить настройки в приложении `Katya`, обновив `AgentSettings`.

Всегда держи наготове fallback-варианты локальных (On-Device) моделей через LiteRT или Ollama на случай отсутствия сети.
