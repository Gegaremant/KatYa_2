# KatYa v3.0.2 Release Notes (Technical & Backstage)

В этом документе собраны технические подробности и изменения "под капотом", реализованные в рамках подготовки обновления до версии 3.0.2.

## 0. Хотфиксы 3.0.1 - 3.0.2
- **Koin (DI)**: Исправлена критическая ошибка при запуске приложения `NoBeanDefFoundException`, возникавшая из-за отсутствия `audioModule` в загрузке `KatyaApplication.kt`.
- **UI Настройки**: Исправлена проблема нечитаемого черного текста на темном фоне в карточках STT/TTS в настройках агента.
- **UI Права доступа**: Исправлен баг, при котором выданные системные разрешения не отображались с зеленой галочкой при возврате из настроек системы. Теперь используется `LifecycleEventObserver` для автоматического обновления состояний при `ON_RESUME`.
- **Сервисы**: Добавлена интеграция бесплатного прокси `freeGPT` от Кати. Кнопка "Добавить сервис" разделена на "Добавить бесплатный сервис" (которая добавляет freeDeepSeek, freeGPT и стандартный Kai9000) и "Добавить свой сервис".

## 1. Миграция на Termux (Песочница)
- **Новый загрузчик (`RootfsDownloader`)**: Полностью переписан алгоритм скачивания базовой системы. Вместо Alpine Linux теперь напрямую с GitHub скачивается и разворачивается `bootstrap-aarch64.zip` (базовая система Termux).
- **Символические ссылки**: Внедрен парсинг файла `SYMLINKS.txt` для корректного воссоздания символических ссылок внутри песочницы, так как стандартный `unzip` на Android не всегда с ними справляется.
- **Интеграция Proot**: Изменены пути монтирования в `ProotExecutor`. Файловая система песочницы теперь пробрасывается в нативный префикс Termux (`/data/data/com.termux/files/usr`). Туда же проброшены `/sdcard` и `/storage`.
- **Пакетный менеджер**: Вместо `apk` теперь используется нативный `apt`. При инициализации песочницы автоматически устанавливаются `python`, `sqlite` и `curl`. За счет этого сохранена возможность программно скачивать любые инструменты, обходя ограничения Android-манифеста.

## 2. Интеграция VLESS / Xray
- Бинарный файл `xray-core` для архитектуры ARM64 интегрирован непосредственно в сборку приложения (добавлен как `libxray.so` в `jniLibs`). 
- Система Android автоматически распаковывает этот файл при установке приложения в `nativeLibraryDir`. На этапе настройки песочницы этот бинарник копируется в виртуальную директорию Termux.
- Xray теперь доступен полностью оффлайн без необходимости скачивания из сети.
- `VlessProxyManager` перенастроен для использования `xray` в новом окружении Termux.

## 3. Демон и Логирование
- **Root Логи**: Устранена ошибка, из-за которой логи root-доступа писались только один раз (или не писались вовсе при повторных вызовах). Проблема заключалась в том, что оболочка `su` имеет собственное mount-пространство и часто конфликтует с FUSE-монтированием `/sdcard`. Теперь запись логов идёт напрямую в физическую директорию `/data/media/0/Katya/`, минуя слой FUSE.
- **Фоновый Демон Задач**: Настроен и подтвержден механизм `DaemonService` + `TaskScheduler`, который через `START_STICKY` держит фоновую активность и выполняет запланированные задачи (скрипты, напоминания), обеспечивая автономную работу ИИ.

## 4. Расширение полномочий (GOD_MODE)
- В `AndroidManifest.xml` добавлены обширные системные разрешения Android.
- Обновлен модуль `RootHelper`: реализован автоматический запрос и выдача этих разрешений через консоль с правами суперпользователя (с использованием команд `pm grant` и `appops`), что предоставляет приложению максимальный уровень доступа к устройству.

## 5. UI и Пользовательский интерфейс
- Вкладка "Серверы" полностью переведена на дизайн "островков" (отдельные карточки `SettingsCard`).
- Добавлено плавное раскрытие списка конфигураций VLESS и SSH, а также кнопка добавления при включении соответствующих тумблеров.
- Исправлены проблемы с выбором файлов (возвращена поддержка камеры и любых форматов файлов).
- Исправлена верстка текста "Очистить очередь" на вкладке "Агент" (устранено вертикальное отображение).

## 6. Звук и Audio Focus (Эксклюзивный перехват)
- Переработана логика захвата фокуса `AudioFocus` при работе с микрофоном и генерации речи. Вместо простого приглушения звука (ducking), теперь используется эксклюзивный захват `AUDIOFOCUS_GAIN_TRANSIENT_EXCLUSIVE`.
- Музыка в сторонних плеерах корректно ставится на паузу во время прослушивания или речи Кати и автоматически возобновляется.
- Кнопка микрофона больше не вызывает синее полноэкранное Intent-окно. Используется скрытый нативный Android `SpeechRecognizer`, который стримит `partialResults` (текст) прямо в поле ввода на лету.

## 7. Локальные STT и TTS (Вкладка Агент)
- Во вкладку "Агент" добавлены элементы интерфейса (в стиле "островков") для выбора движков распознавания и синтеза речи.
- Интегрирована поддержка скачивания и выбора локальных моделей (`Whisper` для STT и `Piper` для TTS), обеспечивая работу полностью оффлайн без сторонних API. Оставлены заглушки для настройки облачных API в будущем.

## Итог
Обновление **KatYa v3.0.0** — это колоссальный скачок к полноценному автономному AI-агенту с поддержкой локальных моделей, фонового режима и эксклюзивного управления звуком.
